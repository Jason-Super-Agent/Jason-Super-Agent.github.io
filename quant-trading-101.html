01五分钟理解量化交易 TL;DR

如果你只想带走 6 句话，请记住这些。每一句都会在后面的章节里展开。

① 量化交易 = 系统性地找“可重复的收益来源”

不是“用程序预测股价”。它更像一条流水线：从大量数据中寻找稳定的统计规律（Alpha），然后严格地控制风险、成本、流动性和执行，把规律变成钱。

② Alpha 是能力，Beta 是市场

Beta 是“市场涨你也涨”的那部分；Alpha 是“市场解释不了、来自策略本身”的那部分。买指数就能拿到 Beta，所以真正值钱的是 Alpha。量化交易员天天想着“去 Beta、抓 Alpha”。

③ Sharpe 衡量“风险调整后的收益”

高收益 ≠ 好策略。赚 30% 但波动 60% 的策略，可能不如赚 12% 但波动 8% 的策略。Sharpe Ratio 就是“每承担一单位风险，换来多少超额收益”。

④ 期权是“观点的表达工具”

一张期权同时包含三个变量：方向（涨/跌）、波动率（会不会大动）、时间（还剩多久）。Greeks 就是管理这三个变量的仪表盘：Delta 看方向、Vega 看波动率、Theta 看时间。

⑤ 做空波动率 ≠ 看空股票

卖期权赚的是“时间价值和隐含波动率溢价”。真正押注的是：市场实际波动（RV）< 期权隐含波动（IV）。2018 年 2 月做空 VIX 的产品（XIV）一夜跌掉 85% 后被清算，是这一课最好的反面教材。

⑥ 回测赚钱 ≠ 实盘赚钱

交易成本、滑点、市场冲击、容量（钱太多策略就失效）会把“纸面收益”吃掉。量化交易员一半的工作，是在处理这些“看不见的损耗”——包括 TQQQ 这类杠杆产品的波动损耗。

怎么读这份报告： 全程围绕 4 个案例展开——Case A：QQQ（讲 Beta、波动率、Sharpe、TQQQ）、Case B：一只 $100 的股票（讲期权与 Greeks）、Case C：S&P 500 / SPX（讲 VIX 与隐含波动率）、Case D：一个虚构的量化策略（讲 Alpha、容量、成本、ML）。同一批例子反复出现，比孤立背定义容易记住。

03Alpha / Beta / Sharpe 收益从哪来？冒了多少风险？

这是整个量化世界最重要的三个词。先记住一句话：Beta 是市场给你的钱，Alpha 是你自己挣的钱，Sharpe 是“每冒一单位风险换多少钱”。

Beta（贝塔）＝ 对市场的敏感度

衡量你的策略（或股票）对“整个市场”涨跌的敏感程度。Beta = 1：市场涨 1%，你约涨 1%；Beta = 2：市场涨 1%，你约涨 2%；Beta = 0：市场怎么动都跟你无关。它回答的是：你暴露在市场风险上多少？

Alpha（阿尔法）＝ 市场解释不了的那部分收益

用 Beta 能解释的收益扣掉之后，剩下的、来自策略本身能力的部分。它回答的是：抛开市场，你赚的钱是运气还是本事？

Sharpe（夏普比率）＝ 风险调整后收益

衡量“每承担 1 单位波动（风险），拿到多少超额收益”。它回答的是：同样是赚钱，谁的赚钱过程更稳？

公式与直觉（本科生能看懂的程度）

R策略 ≈ Rf ＋ β × (R市场 − Rf) ＋ α含义：策略收益 ≈ 无风险收益 ＋ “市场涨跌带来的部分” ＋ “策略自己挣的部分”。其中 Rf 是无风险利率（比如短期国债利率），R市场 − Rf 是市场超额收益。
β = Cov(R策略, R市场)Var(R市场)直观理解：β 是“市场每动 1%，策略平均跟着动百分之几”。算法上它是策略收益与市场收益的协方差除以市场收益的方差——不必会算，知道它衡量“联动程度”即可。
Sharpe = R策略 − Rfσ策略分子：策略跑赢无风险利率的部分（超额收益）；分母：策略收益的波动率（风险）。单位是“倍”，年化后 Sharpe = 1 算不错、2 很好、3 以上非常优秀。

用 Case A（QQQ）讲清 Alpha 和 Beta 的区别

假设 QQQ 这一年涨了 20%（把 QQQ 当作“市场”的代理）。现在有两个策略：

策略①：满仓 QQQ策略②：市场中性策略
Beta≈ 1（市场涨它也涨）≈ 0（市场涨跌与它无关）
这一年收益+25%+25%
其中“市场给的”（Beta 部分）约 +20%约 0
其中“自己挣的”（Alpha）约 +5%约 +25%
下一年市场跌 20% 时大概率跟着跌约 20%仍可能赚钱（与市场无关）

看出关键了吗？策略①的 25% 里，20 个百分点是“市场顺风”，只有 5 个百分点是本事；策略②的 25% 几乎全是本事（当然，它可能承担了别的风险，见下文）。这就是为什么量化交易员反复问：“你赚的是 Beta 还是 Alpha？”

为什么量化交易员总是强调“去 Beta”？

Beta 是“便宜的商品”

想要 Beta，买指数基金就行了，成本极低（QQQ 费率 0.18%–0.20%[4][5]）。如果策略收益主要来自 Beta，客户凭什么付你高额管理费？

Beta 可以“用杠杆造出来”

纯 Beta 收益可以用融资放大（也能被 TQQQ 之类的产品放大）。既然能廉价复制，就不算稀缺能力。稀缺的是 Alpha。

去 Beta 才能评价“能力”

牛市里人人赚钱，分不清谁有本事。把 Beta 对冲掉（做成市场中性），剩下的收益才近似等于“策略的真实能力”。

控制风险 / 回撤

Beta 意味着“市场崩你也崩”。对冲掉 Beta 后，回撤不再受大盘绑架，更符合对冲基金“绝对收益”的定位。

“高收益”和“好策略”为什么不是一回事？——Sharpe 登场

两个策略给你选（假设无风险利率 ≈ 2%）：

策略年化收益年化波动率最大回撤（近似）Sharpe = (收益−2%) / 波动
策略 A：追涨杀跌型+30%60%约 −45%(30%−2%)/60% ≈ 0.47
策略 B：稳健型+12%8%约 −6%(12%−2%)/8% ≈ 1.25

A 收益更高，但 Sharpe 只有 0.47；B 收益低一半，Sharpe 却高出近三倍。为什么？因为 A 的赚钱过程“大起大落”，可能亏 45% 你根本拿不住；而 B 几乎一路平稳。Sharpe 高 = 同样的风险换来了更多收益 = 更容易被资金追捧。 加杠杆可以放大 A 的收益，但波动也同步放大，Sharpe 基本不变——所以“高收益”本身说明不了策略质量。

收益 vs Sharpe：谁更“好”？
左：年化收益与年化波动（%）；右：Sharpe 比率（示意数值，Rf=2%）。策略 A：30%/60% → Sharpe≈0.47；策略 B：12%/8% → Sharpe≈1.25。

04期权基础 用一只 $100 的股票讲透 Call 和 Put

期权不是“高级赌博工具”，而是一种“观点的表达方式”。先建立四个基本问题：这是买还是卖？赌的是涨还是跌？行权价在哪？还剩多久到期？

两个基本工具：Call 和 Put

Call（看涨期权）

买方获得“以行权价买入”的权利。赌的是：到期时股价会涨过行权价。买 Call = 付一笔钱（权利金），把“上涨的收益”买下来。

Put（看跌期权）

买方获得“以行权价卖出”的权利。赌的是：到期时股价会跌破行权价。买 Put = 付一笔钱，买一份“下跌的保险”。

四个要素是什么例子（本章全程使用）
Strike Price 行权价约定买卖的价格（K）K = 105（Call）、K = 95（Put）
Expiration 到期日权利生效的截止时间1 个月后到期
Premium 权利金买方向卖方支付的价格（教学示意值，与 Black-Scholes 在 σ=30%、30 天、r=2% 下一致）Call 付 $1.6 / 股，Put 付 $1.4 / 股
合约单位1 张期权 = 100 股标的（美股标准）1 张 Call 的权利金 = $1.6 × 100 = $160

Case B 第一幕：Long Call——买一张行权价 $105、一个月到期的 Call

股票现在 $100。你花 $1.6/股（一张 = $160）买了一张 Call：行权价 $105，一个月后到期。逐步推演：

情形发生了什么你的盈亏（每股）
到期时股票 涨到 $120你有权以 $105 买入，马上以市价 $120 卖出 → 内在价值 = 120 − 105 = $15+$13.4（= 15 − 1.6 权利金）
一张合约 +$1,340
到期时股票 不涨，$100行权价 105 > 市价 100，行权没有意义 → 期权作废，内在价值 = 0−$1.6（亏掉全部权利金）
一张合约 −$160
到期时股票 暴跌到 $80更不可能行权 → 期权作废−$1.6（最大损失 = 权利金）

核心结论 1：买 Call 的最大损失是固定的（权利金），但上涨收益是开放的。 这就像买了一张“上涨彩票”：亏最多亏票价，赢可以赢很多。

核心结论 2（计算）： 到期收益 = max(ST − 105, 0) − 1.6。盈亏平衡点 = 行权价 + 权利金 = $106.6：股票涨过 106.6 才真正开始赚钱。

核心结论 3（时间的作用）： 上面的推演全部发生在“到期那一刻”。在到期之前，哪怕股票只涨到 $106，这张 Call 也值 超过 $1——因为未来一个月还有继续上涨的可能。到期前期权价格 = 内在价值 ＋ 时间价值。这一点是第 05 章 Theta 和第 06 章波动率的伏笔。

Case B 第二幕：Long Put——买一张行权价 $95、一个月到期的 Put

同样这只 $100 的股票，你花 $1.4/股 买了一张 Put：行权价 $95，一个月后到期：

情形发生了什么你的盈亏（每股）
到期时股票 跌到 $80你有权以 $95 卖出市价 $80 的股票 → 内在价值 = 95 − 80 = $15+$13.6（= 15 − 1.4 权利金）
到期时股票 不跌，$100行权价 95 < 市价 100，放弃行权 → 作废−$1.4（最大损失 = 权利金）

到期收益 = max(95 − ST, 0) − 1.4，盈亏平衡点 = 95 − 1.4 = $93.6。 买 Put 就像买保险：跌了保险公司赔你（行权获利），不跌最多损失保费。

先分清三个状态：ITM / ATM / OTM

状态含义Call（K=105）示例Put（K=95）示例
ITM（In The Money，实值）立即行权能赚钱，有内在价值股价 > 105（如 $120）股价 < 95（如 $80）
ATM（At The Money，平值）行权价 ≈ 现价股价 ≈ 105股价 ≈ 95
OTM（Out of The Money，虚值）立即行权不赚钱，只有时间价值股价 < 105（如 $100，我们的例子）股价 > 95（如 $100）

再说“卖”：Sell Call 与 Sell Put

Sell Call（卖出 Call / 裸卖看涨）

你把“上涨的权利”卖给别人，先收 $1.6 权利金。代价是：股票暴涨时你要按行权价卖给他——理论上亏损无限（股票可以一直涨）。这是四个基本动作里最危险的一个。

Sell Put / Cash-Secured Put（卖出 Put / 现金担保看跌）

你把“下跌的保险”卖给别人，先收 $1.4 权利金。代价是：股票跌破 95 时你要按 $95 接盘。现金担保 = 账户里预留 $95×100 的资金，确保接得起。最大亏损 = 行权价 − 权利金（理论上股票跌到 0）。

Covered Call（备兑看涨）

你已经持有 100 股（成本 $100/股），再卖一张 Call（K=105，收 $1.6）。股票涨过 105，你被行权，以 105 卖出：总收益 = (105−100) + 1.6 = $6.6/股 封顶；股票不涨/微跌，你多收 $1.6 补贴。缺点是上涨空间被封死。

四个动作的“谁赚谁亏”

期权是零和游戏：买方赚的钱 = 卖方亏的钱（忽略手续费）。买 Call / 买 Put 的风险有限、收益开放；卖 Call / 卖 Put 是收益有限（最多权利金）、风险开放。记住这个不对称，是理解第 07 章策略框架的钥匙。

05Greeks 管理期权组合的四个仪表盘

期权价格不是一条直线，它同时被五个变量牵着走。Greeks 就是这五个变量各自的“敏感度”，是交易员管理期权风险的仪表盘。核心心法：Delta 管方向，Gamma 管方向变化的速度，Theta 管时间，Vega 管波动率。

Delta（Δ）

股票涨 $1，期权价格变多少。Call 的 Delta 在 0~1 之间，Put 在 −1~0 之间。ATM 的 Call 约 +0.5：股票涨 $1，Call 约涨 $0.5。

Gamma（Γ）

Delta 会变化，Gamma 就是 Delta 的变化速度。Gamma 高 = Delta 不稳定 = 需要对冲得更勤快。ATM、临近到期的期权 Gamma 最大。

Theta（Θ）

每过一天，期权价格损失多少（时间价值衰减）。买方付 Theta，卖方收 Theta。

Vega（ν）

隐含波动率每涨 1 个百分点，期权价格变多少。买方收 Vega（波动率上涨有利），卖方付 Vega。

为什么交易员天天盯 Greeks？ 因为他手里往往有几百张不同行权价、不同到期日的期权。直接看“整体价格”看不出风险在哪；把组合拆成 Δ/Γ/Θ/Vega，就能回答：“市场涨 1% 我赚多少？波动率跳 2 个点我亏多少？明天开盘我又会损失多少时间价值？”

深入 Theta：为什么“时间”对买方不利、对卖方有利？

期权里除了内在价值，还有时间价值——“未来还有可能发生好事”的价钱。时间每过去一天，这个可能性就少一点，时间价值就折旧一点：

  • 买方持有时间价值，每天都在“付费”（Theta 为负）。买 1 个月 Call 付 $1.6，其中大部分都是时间价值——每天醒来它都在缩水，股票不动就亏。
  • 卖方卖出时间价值，每天都在“收租”（Theta 为正）。什么都不做，只要股价不出现大变动，时间流逝本身就是利润。
  • 临近到期加速衰减：离到期越近，时间价值缩水越快（尤其 ATM 期权）。卖方的“收租”在最后两周最肥，买方的“失血”也在最后两周最猛。
一句话： 时间站在卖方一边，波动站在买方一边（Vega）。所以“卖期权”本质上是在赌 “时间价值能赚回来，且市场不会出现大波动”——这直接通向第 06 章的做空波动率。

深入 Gamma：为什么 Delta 不是固定的？为什么临近到期 ATM 的 Gamma 飙升？

Delta 不是常数。 一张 ATM Call 的 Delta 约 0.5，但股价每动一下 Delta 就变：股价涨，Call 越来越实值，Delta 向 1 靠拢；股价跌，Delta 向 0 滑落。Gamma 衡量的就是这个“Delta 漂移的速度”。

为什么临近到期、ATM 的 Gamma 特别大？ 因为这时候“结局只剩两种”的博弈感最强：到期时它要么实值（Delta→1 或 −1）、要么作废（Delta→0），中间没有缓冲。剩 1 天、股价恰好等于行权价时，Delta 会随着股价每动一美元在 0 和 1 之间剧烈摇摆——Gamma 极大，Delta 极不稳定。

  • 对买方：高 Gamma 是双刃剑——行情来了 Delta 快速变大、越赚越多（正 Gamma 有利）；但正 Gamma 通常伴随负 Theta，等待期天天失血。
  • 对卖方：负 Gamma = 行情越走越不利时，亏损加速放大；好处是每天收 Theta。这就是“在压路机前捡钢镚”的数学来源。

深入 Vega：为什么交易员总在谈“波动率”而不只谈涨跌？

原因有两层。第一，期权价格对波动率极其敏感：波动率上升 = 未来价格分布变宽 = 大涨大跌的可能都增加 = 所有期权都更贵（Vega 为正）。第二，当交易员把 Delta 对冲掉以后，“涨跌”这个变量被拿走了，剩下的盈亏几乎完全由波动率驱动。这时候他持有的本质上是“波动率头寸”——赚不赚钱，取决于实际波动比隐含波动大还是小。这也解释了为什么同一只股票、同一个到期日，市场会给期权报出一个“隐含波动率”（下一章展开）。

06波动率 Volatility 整份报告的重点：风险、期权定价与做空波动率

波动率（Volatility）是连接“风险”、“期权定价”和“VIX”的核心变量。读懂这一章，你就听懂了一半的量化黑话。

1) 什么是波动率？先看两个例子

两只股票，各自的“日内轨迹”如下（都是 5 个时点）：

时点12345终点
股票 A$100$101$99$100$101+1%
股票 B$100$120$80$110$90−10%

A 在 99~101 之间温和波动；B 在 80~120 之间坐过山车。波动率衡量的不是“涨还是跌”（方向），而是“动得多剧烈”（幅度）。 数学上，波动率 ≈ 一段时间内日收益率的标准差，再年化：

σ年化 = 日收益标准差 × √252252 是美股一年约有的交易日数量。直觉：年化波动率 30% ≈ 股价一年内约 68% 的概率落在“±30%”这个范围附近（更准确地说，对应 1 个标准差）。

为什么波动率 = 风险？ 因为波动大意味着“结果的不确定性大”：既可能大涨也可能大跌。对于需要控制回撤的组合，波动率就是“风险”最常用的代理指标。

2) 三个“波动率”：HV / RV / IV

Historical Volatility（历史波动率）

用过去的股价数据算出来的波动率。回答：过去一个月/一年，它实际动了多少？

Realized Volatility（已实现波动率）

在一段已经过去的时间区间里实际发生的波动。与“历史波动率”几乎是同族概念，区别只在于口径（用多长窗口、怎么采样）。交易员说“这周 realized 很低”，意思是市场这周很平静。

Implied Volatility（隐含波动率，IV）

从期权价格里反推出来的波动率。回答：期权市场现在为“未来”定价了多大的波动？ 这是第 2 小节的绝对主角。

3) 为什么 Implied Volatility 如此重要？

第一步：期权价格天然包含“对未来的猜测”。 一张期权值多少钱，取决于未来价格可能怎么分布——而“分布有多宽”正是波动率。所以：期权价格 ≈ 市场对“未来波动”的定价。

第二步：IV 是这个定价的“读数”。 交易员把当前期权市场价格代入定价模型（如 Black-Scholes），反解出能让模型价格恰好等于市场价格的 σ——这个 σ 就是 IV。

第三步：同一个股票、同一个到期日，为什么“有一个 IV”？ 因为流动性最好的 ATM 期权把市场对未来波动的共识“暴露”了出来。实际操作中，不同行权价的 IV 并不完全一样（会形成微笑/斜偏曲线，即 volatility smile / skew），但市场总会围绕某个“共识水平”交易——这正是“市场给这只股票的未来 30 天波动定了个价”。

关键对比： HV 看后视镜（过去发生了什么）；IV 看挡风玻璃（市场预期未来发生什么）。IV 高 = 期权贵 = 市场预期未来大波动（可能是真担心，也可能是有人在抢买保护）。

4) 做空波动率：卖期权到底在赌什么？

这是量化世界里被误解最深、也最有故事性的操作。先破除一个错误观念。

“卖期权” ≠ “认为股票不会跌”。 裸卖 Call 的人最怕股票暴涨（要按行权价交出股票）；卖 Put 的人最怕暴跌（要接盘）。而卖 Straddle（同时卖 Call+Put）的人两边都怕——怕的是“任何方向的大幅波动”。所以做空波动率押注的从来不是方向，而是：
做空波动率的盈利条件：实际实现的波动率（RV）< 期权隐含的波动率（IV）卖期权时先收下 IV 定价的权利金；只要到期前实际波动没有“用满”这个 IV，时间价值被吃掉的只是部分，剩余权利金就是利润。反之，一旦实际波动远超 IV（暴涨或暴跌），亏损会急剧放大。

“做空波动率”和“做空股票”的区别： 做空股票赌的是股价下跌；做空波动率赌的是波动变小（无论涨跌，只要别大动）。一只慢牛股会狠狠惩罚做空者吗？不会——它波动小、IV 低，做空波动率的仓位反而舒服。真正杀死做空波动率的是跳空、闪崩、暴涨暴跌这类“波动率事件”。

08TQQQ vs QQQ 用杠杆产品讲透“波动损耗”与“路径依赖”

TQQQ 是 ProShares 发行的“纳指 100 每日 3 倍”ETF（每日追求纳指 100 日收益的 3 倍）[6]。很多新手以为它等于“QQQ × 3”，这是本报告要纠正的最大误区之一。

1) “3x daily leverage” 是什么意思？

关键是 daily（每日） 这个词：TQQQ 的合约承诺是——每一个交易日，TQQQ 当天的收益 ≈ QQQ 当天收益 × 3。它不承诺“长期收益 = QQQ 长期收益 × 3”。

Daily Reset（每日重置）：每个交易日收盘后，基金重新调整杠杆仓位，让第二天的目标仍然是“当日 3 倍”。这意味着昨天的盈亏会被“滚入”今天的基数——复利效应让长期结果严重偏离简单的 3 倍。

2) 数字模拟：为什么 QQQ 回到原点，TQQQ 却亏了？

用户最经典的例子：Day 1 QQQ +10%，Day 2 QQQ −10%。

路径Day 0Day 1 后Day 2 后总收益
QQQ100110（+10%）99（−10%）−1%
TQQQ（每日 3 倍）100130（+30%）91（−30%）−9%
“朴素 3 倍”幻觉（3 × QQQ 总收益）100——−3%

QQQ 两天合计只亏 1%，TQQQ 却亏了 9%——比“3 × (−1%) = −3%”还多亏 6 个百分点。这 6 个百分点就是 Volatility Drag（波动损耗），也叫 Volatility Decay。

(1 + 3r₁)(1 + 3r₂) = 1 + 3(r₁ + r₂) + 9·r₁r₂当 r₁、r₂ 异号（先涨后跌或先跌后涨）时，交叉项 9·r₁r₂ 为负 → 损耗出现。波动越大、来回越频繁，损耗越大。数学上可以说：杠杆产品的长期收益 ≈ 3× 基准收益 −（由日波动平方累积出的损耗）。

3) 路径依赖：同一个“平均日收益”，不同的结果

杠杆产品的结局强烈依赖路径顺序，而不只是起点终点：

  • 趋势市场（单边上涨）：每天同向复利，TQQQ 的 3 倍滚雪球，长期表现往往超过“3 × QQQ 总收益”（正凸性帮你放大）。
  • 震荡市场（来回拉扯）：涨跌互现，交叉项不断累积为负，TQQQ 显著跑输“3 × QQQ 总收益”，甚至 QQQ 回到原点它还在亏。
  • 长期持有：除了波动损耗，还要付 约 0.82%–0.97% 的年费率（TQQQ 官方：毛费率 0.97%、净费率约 0.82%–0.84%[6][7]），以及隐含的融资成本。而 QQQ 费率仅约 0.18%–0.20%[4][5]。所以“长期 buy-and-hold TQQQ”的代价远不止手续费。
结论： TQQQ 最大的代价不是“佣金”，而是路径依赖 + 波动损耗 + 费率/融资成本 + 极端回撤风险。它是短期战术工具，不是“QQQ 的 3 倍代餐”。

09VIX：所谓的“恐慌指数” 准确地说，是市场对未来波动的定价

VIX 常被媒体叫“恐慌指数”。这个外号方便，但不准确。准确的定义是：由 S&P 500 指数期权（SPX）价格推算出的、市场对未来 30 天标普 500 波动率的预期（年化）[1][2][3]。

1) VIX 到底是什么、怎么算出来的

它是 IV，不是 HV

VIX 不是拿历史数据算的（那不是历史波动率），而是从当前 SPX 期权价格反推出来的隐含波动率。它回答的是：期权市场现在认为，未来 30 天标普 500 会波动多少？

它是“一篮子期权”的加权读数

Cboe 取近月与次月、到期日约 23–37 天的 SPX 期权，对大量 OTM 看涨和看跌期权的买卖中间价做方差互换式的加权（model-free 方法），得到 30 天预期方差，再开方年化：VIX = σ × 100。所以 VIX = 20 ≈ 市场预期未来 30 天年化波动约 20%[1][2]。

和 S&P 500 的关系：负相关

历史上两者强烈负相关：市场大跌 → 抢购 Put 保护 → 期权变贵 → 隐含波动率上升 → VIX 冲高。反过来，平静上涨时 VIX 走低（常年在 12–20 附近徘徊）。

为什么暴跌时 VIX 总暴涨？

两点：一是供需——恐慌时人人买保险（Put），期权被抢贵；二是凸性——大跌时价格分布变宽，隐含波动率自然上移。另外，VIX 的上涨通常比下跌快得多（人们抢保险的速度远快于退保险）。

3) 关键澄清：VIX 不是“恐慌程度调查问卷”

不要把 VIX 简单写成“VIX = 市场恐慌程度”。 它是期权市场对波动率的定价，是交易出来的价格，不是情绪量表。恐慌时它确实往往很高，但高 VIX 也可能由“大家都在买保险”或“期权被逼空”造成——它测量的是“未来波动被市场标价多少”，仅此而已。
VIX 能直接买吗？ 不能直接买卖“VIX 指数”本身（它是计算出来的数字）。想表达波动率观点，要用 VIX 期货、VIX 期权，或者 VXX / UVXY 这类基于 VIX 期货的产品。还要注意：这些产品本身也有滚动换仓成本和升贴水，长期持有 VXX 会因期货展期而持续损耗——和 TQQQ 的“复利损耗”是两种不同的损耗。

10流动性：股票和期权一样吗？ “这只股票很流动” ≠ “它的所有期权都流动”

流动性（Liquidity）决定一件事：你想交易时，能不能按接近“合理价格”的价位、以足够大的量成交。

1) 股票 vs 期权：一个“点” vs 一张“面”

股票：单一标的

一只股票（如 QQQ）只有一个交易标的、一个市场。买卖双方聚集在同一个地方，深度好、价差小。流动性问题相对简单。

期权：一张 liquidity surface（流动性曲面）

一只股票的期权却是“一大片”：不同行权价 × 不同到期日 × Call/Put。每个格子都是独立的“市场”，都有自己的买卖价差、成交量、持仓量。

推论： “QQQ 这只股票非常流动”完全不意味着“QQQ 的每一张期权都流动”。通常只有 ATM 附近、近月到期 的期权最活跃（流动性最集中）；深度 OTM、超远月的期权可能一天都没几手成交，价差宽得吓人。

2) 衡量流动性的六个指标

Bid-Ask Spread（买卖价差）

买价与卖价之差。价差越小越流动。对期权来说，价差往往比佣金贵得多（详见第 15 章）。

Trading Volume（成交量）

单位时间成交的合约/股数。量大 = 参与者多。

Open Interest（持仓量）

市场上未平仓的合约总数。它反映“存量深度”——OI 高的合约，即使当天没人交易，盘口也往往更厚。

Market Depth（市场深度）

盘口挂单的数量与厚度。深度够，大单才不会把价格打穿。

Slippage（滑点）

你预期成交价与实际成交价之差。流动性越差，滑点越大。

Liquidity Concentration（流动性集中度）

成交集中在哪些合约（通常 ATM + 近月）。这告诉你：你想交易的那个“格子”到底有没有人陪你玩。

3) 为什么这对量化策略是生死问题

策略回测时假设“按中间价成交”，但真实世界你买要付卖价、卖要收买价，还要承担滑点和冲击。如果一个策略专挑“冷门期权格子”交易：

  • 每次进出都吃宽价差 → 高频交易的成本可能吃掉全部 Alpha；
  • 想平仓时发现对手盘稀少 → “进得去出不来”；
  • 资金量大时，你的订单本身就是市场 → 自己把自己的价格打坏（这直接通向下一章：容量）。
一句话： 流动性的本质是“交易的对手盘成本”。量化交易员把“能不能成交、以什么价格成交”当作策略设计的一等公民，而不是最后才考虑的执行细节。

11策略容量 Capacity 为什么“年化 30%”不代表多少钱都能赚 30%

Capacity（容量）= 一个策略在不显著损害收益的前提下，最多能管理多少钱。 这是量化里最重要、也最容易被普通投资者忽略的概念之一。

1) 核心直觉：Alpha 是“一桶水”，不是“一条河”

假设一个策略的 Alpha（超额收益）来源于某个市场里有限的“定价错误”机会。这个机会每年大概值 固定的那么多钱（比如 $1,000 万）。那么：

管理资金年化 Alpha（毛）发生了什么
$1,000 万100%（$1,000 万 ÷ $1,000 万）机会足够容纳，表现惊人
$1 亿10%（$1,000 万 ÷ $1 亿）开始拥挤，每笔单子都推动价格
$10 亿1%（$1,000 万 ÷ $10 亿）机会被淹没，收益趋近于 0（甚至为负）

更糟的是：资金变大不只是“摊薄 Alpha”，还会制造反噬——你的订单本身在冲击市场，把机会的价格直接打没（market impact），同时持仓变大会吸引更多竞争者进入同一机会。

2) 影响容量的因素

市场流动性

交易对象本身有多少成交量。小盘股、冷门期权的容量天然小。

换手率（Turnover）

策略每天换仓多少。换手越高，每单位资金产生的冲击成本越大。

市场冲击（Market Impact）

自己买卖把价格推得多远。资金越大，冲击越大。

滑点 / 买卖价差

进出场的固定“摩擦”，高频策略最敏感。

Alpha Decay（Alpha 衰减）

信号的生命周期：有的信号几分钟就失效（容量小但可重复），有的信号几周才失效（容量大）。

持仓集中度 / 做空可得性

仓位越集中、做空标的越稀缺，容量越小。

3) 具体例子：一个“小市值策略”的容量曲线

一个典型的小市值股票策略（示意模型）：

  • $100 万：非常好做——订单小到不引起注意，摩擦可以忽略，年化可能 30%+；
  • $1 亿：开始明显影响市场——每笔订单都吃掉一部分流动性和价差，年化降到 10% 出头；
  • $10 亿：策略可能失效——买入行为本身就是市场，Alpha 被冲击成本完全吞噬，甚至亏损。

这就是为什么对冲基金会主动“封盘”：不是不想赚钱，而是保护已有投资者——让新钱进来会把所有人的收益一起拉垮。管理费是 AUM 的函数，但业绩是 capacity 的函数。

12天级别 vs 分钟级策略 交易频率 ≠ Beta——但两者确实有统计倾向

有人问：日频策略和分钟级（高频）策略，哪个和 Beta 的相关性更高？直觉会说“日频更高”，但真实答案更微妙。先记住铁律：交易频率 ≠ 市场暴露。

1) 用六个维度拆开看

维度分钟级 / 高频策略（典型画像）日线级策略（典型画像）
持有期（Holding Period）秒~分钟，通常当天进出数天~数周甚至更长
市场暴露（Market Exposure）往往日内即时对冲，敞口短暂且小往往持有敞口过夜/过周
隔夜风险（Overnight Risk）收盘前基本清仓，几乎不承担隔夜跳空承担隔夜/周末跳空风险
日内市场中性（Intraday Neutral）容易做成“日内中性”：日内 Delta 近似为 0难做完全中性（但可以每日收盘对冲）
因子暴露（Factor Exposure）通常很小——持仓太短，来不及积累风格因子常携带价值/动量/规模等风格暴露
调仓（Rebalancing）极频繁，对交易成本极度敏感低频，单笔成本容忍度高

2) 为什么“高频更容易中性、低频更容易带 Beta”？

这不是必然规律，而是统计倾向 + 工程约束：

  • 隔夜风险太难控制：高频策略如果持仓过夜，要面对开盘跳空、隔夜消息等完全不可预测的风险，而它的优势（快进快出）根本用不上——所以干脆收盘清零，顺带把 Beta 也清掉了。
  • 低频策略付得起“持有”的代价：日线信号本来就靠“方向/因子”赚钱，持有几天才能兑现，天然带着市场暴露；要做成市场中性也可以（每天用指数期货对冲），但很多低频策略刻意保留方向暴露，因为那本身就是它的 Alpha 来源之一。

3) 反例：频率与 Beta 可以完全脱钩

分钟级 ≠ 低 Beta

一个日内策略如果只做多、从不做空、收盘也满仓，它每天暴露在市场的涨跌里，对日收益的 Beta 可能接近 1——哪怕它持仓只有几分钟。频率低不了它的市场暴露。

日线级 ≠ 高 Beta

一个日频策略如果每天收盘前用指数期货把多头空头对冲干净（delta-neutral），它可以做到 Beta ≈ 0——持仓几天，但对市场的净暴露为零。它赚的是因子/价差的 Alpha。

结论： “分钟级策略 Beta 低、日频策略 Beta 高”是统计倾向，不是必然规律。判断一个策略的 Beta，要看它的持仓暴露和对冲行为，而不是看它多久交易一次。下次朋友说“我们是个高频中性策略”，你就能明白：高频是频率标签，中性是风险标签，两者是独立的。

13“无风险套利”到底是什么意思？ 以及为什么现实中它几乎不存在

Arbitrage（套利）在教科书里有个美丽定义，在现实世界里却有一堆“但是”。这一章把它们分开。

1) 三个概念，先分清楚

Arbitrage（套利）

广义：利用同一资产/相关资产在不同市场的价格不一致赚钱。核心是“低买高卖同时完成，锁定价差”。

Risk-free Arbitrage（无风险套利）

理想化的套利：同时、确定、零风险地锁定利润。教科书例子：同一资产在 A 市场卖 $100、B 市场卖 $102，同时买 A 卖 B，锁死 $2。

Statistical Arbitrage（统计套利）

用统计模型找“历史上相关、暂时背离”的资产对（如两只走势高度相关的股票），赌它们均值回归。有风险、有概率，赚的是长期期望为正——不是无风险。

2) 教科书例子 vs 现实世界的“但是”

教科书： 黄金在纽约 $100/盎司、在伦敦 $102/盎司，同时纽约买、伦敦卖，每盎司锁死 $2，无论之后价格怎么动都不亏。

现实： 这 $2 的价差在你看清的同一瞬间，已经被全世界最快的人抢走了。而且——

现实摩擦它如何杀死“无风险”
交易成本（Transaction Cost）双边佣金、费用可能超过 $2 的价差
延迟（Latency）你下单的毫秒间，价格可能已经变了
执行风险（Execution Risk）“买 A”成交了，“卖 B”却滑价/没成交——敞口就暴露了
对手方风险（Counterparty Risk）你的对手方（或交易所/清算所）可能违约
融资成本（Funding Cost）占用保证金/资金本身要付利息，持有期间一直在消耗
流动性风险（Liquidity Risk）想平仓时对手盘消失，价差收不回来
模型风险（Model Risk）你以为“同一资产”，其实两边的标的/条款/信用有细微差异（如两家公司、两种到期日）

3) 那量化交易里的“套利”是什么？

现实中的量化“套利”绝大多数是统计套利 / 收敛交易：基于模型和历史关系，赌“价差会回归”，承担方向、波动、流动性和模型风险，靠大量交易 + 期望为正赚钱。比如：

  • 配对交易（Pairs Trading）：两只高度相关的股票，一只暂时偏贵、一只暂时偏便宜 → 做空贵的、做多便宜的，赌价差回归；
  • 指数套利：股指期货相对现货指数出现基差 → 买低卖高，等收敛；
  • 事件/并购套利：并购宣布后，目标公司股价通常折价交易，买入并持有到交割，赚“完成概率 × 价差”。
一句话： 教科书里的 risk-free arbitrage 是理论极限；现实里“套利”二字更多是指“低风险、高胜率、但绝非无风险”的收敛交易。听到有人说“我们在做套利”，可以追问一句：“你们承担的主要风险是什么？”——答案往往比“套利”二字更有信息量。

14机器学习在量化里到底有没有用？ 有用，但要放在对的位置

不回答“ML 很有用”这种空话，也不吹“AI 能预测股票”。把 ML 放进真实的量化流水线里，你自然知道它在哪里发光、在哪里翻车。

1) 量化交易的标准流水线（Pipeline）

① Market Data 市场数据行情、订单簿、新闻、宏观、另类数据（卫星图、信用卡流水……）
↓
② Feature Engineering 特征工程把原始数据加工成“有预测力的输入”：动量、价差、情绪、波动率状态……
↓
③ Signal / Alpha 信号预测未来收益/波动/方向的信号——ML 的用武之地之一
↓
④ Portfolio Construction 组合构建多个信号合成、按风险分配权重
↓
⑤ Risk Model 风险模型预测组合的波动、回撤、因子暴露
↓
⑥ Execution 执行把订单拆成可成交的路径，最小化冲击成本
↓
⑦ PnL 盈亏真实结果回流，反哺特征和模型（研究闭环）

2) ML 在流水线各环节的实际角色

环节ML 做什么现实中的“可信度”
收益预测（Alpha Prediction）从特征预测未来收益信号极弱，是 ML 最难、也最容易被过度宣传的环节
波动率预测预测未来波动率（直接服务期权定价和风险模型）较靠谱：波动率有强自相关（聚集性），ML 有优势
订单簿预测（Order Book）从逐笔/盘口数据预测短期价格方向或成交量高频领域最有效的 ML 应用之一（高维、弱信号但海量样本）
市场状态识别（Regime Detection）识别“现在是趋势市还是震荡市”，切换策略有用，但 regime 切换是滞后指标，容易慢半拍
组合优化在收益、风险、成本约束下求最优权重成熟应用（本质上是最优化问题，ML 只是工具）
执行优化预测市场冲击、决定下单节奏和拆分业界落地最扎实的方向之一

3) ML 在量化里翻车的七宗罪

低信噪比（Low SNR）

金融数据里“真信号”淹没在噪声里，模型很容易把噪声当信号学进去。

非平稳（Non-stationarity）

市场的统计规律会变（regime change）。去年有效的规律，今年可能反过来。

过拟合（Overfitting）

模型把历史细节背得滚瓜烂熟，一到新数据就失效——量化里最常见的死法。

数据泄漏（Data Leakage）

特征里不小心混进了“未来信息”（如用了未复权价格、未来财报），回测神准、实盘扑街。

回测过拟合（Backtest Overfitting）

试了 1000 个参数组合，总有一个回测很漂亮——那是“选择偏差”，不是能力。

交易成本

回测不计成本时 ML 信号看着很美；一加手续费和滑点，收益归零。

容量限制

就算信号是真的，能装的钱也有限（见第 11 章），ML 并不能创造容量。

Regime Change

市场风格切换时，训练出来的模型集体失效——2022 年的加息环境杀死了一堆“低波动”模型。

4) 那到底有没有用？——有条件的答案

结论（有条件地）： ML 在量化里非常有用，但不是“预测股票的神器”。
① 在 订单簿预测、波动率预测、执行优化、市场冲击建模 这类“高维、弱信号、样本海量、目标清晰”的环节，ML 是主力工具；
② 在 纯收益预测 环节，ML 的边际价值取决于特征质量、数据独占性和风控纪律——大多数人在这里赚不到钱，不是因为 ML 没用，而是因为信噪比太低、过拟合太容易；
③ 量化研究的真正壁垒，通常是数据 + 特征 + 执行 + 风控的组合，模型只是其中一环。
所以下次听到“我们用 AI 做量化”，值得追问的是：“用在流水线的哪一环？特征是什么？样本外怎么验证？扣完成本还剩多少？”

15交易成本：期权 vs 股票 先分清“佣金”和“价差”，再谈贵几倍

“期权手续费是股票的多少倍？”——这个问题没有单一答案，因为它混淆了至少五类成本。先把它们拆开（以下以美国市场为主，数据时点 2025–2026 年，来源见文末）。

1) 成本的五层结构

成本层是什么股票（美股主流零售券商）期权（美股）
Commission 佣金券商收的“手续费”普遍 $0[12]常见约 $0.50–$0.65/合约（如 IBKR Pro $0.65，量大可低至 $0.15；部分券商 $0 佣金但另收费用）[12][16]
Exchange Fee 交易所费交易所收的“过路费”（maker/taker 阶梯）通常极低或已含约 $0.02–$0.50/合约 区间，视交易所与订单类型而定（示意）[13][14]
Clearing Fee 清算费OCC（期权清算公司）收—约 $0.025/合约[15]
Regulatory Fee 监管费SEC/FINRA/交易所监管费（ORF 等）SEC 交易费约按卖出金额的 0.0000206 左右，金额极小[12]ORF 约 $0.0006–$0.0023/合约/边（各交易所不同时期不同）[17][18]
Bid-Ask Spread + Slippage + Impact“看不见”的市场成本大盘股价差极窄，通常很小通常比佣金大得多，且随合约冷热程度剧烈变化

2) 那到底“贵几倍”？——给不出一个数，但能给你判断框架

如果只比“佣金”

股票 $0，期权 $0.65/合约——从 0 到有，确实像“无穷倍”。但期权 1 张 = 100 股的名义价值，$0.65 摊到 100 股上 ≈ 每股 $0.0065，按名义金额折算并不离谱。

如果比“全部成本”

大头往往不是佣金，而是买卖价差。一张买卖价差 $0.30 的期权，来回就是 $0.60/股（一张 $60），远超佣金。冷门合约价差几美元都正常——“期权更贵”主要是贵在价差和滑点，不是贵在佣金。

如果比“真实可成交价”

还要加上冲击成本：你的单子多大、市场多深。对机构来说，冲击成本通常远大于佣金（这也是第 10、11 章要强调的）。

一个随手算的参考

假设用 IBKR 交易 1 张 $3 权利金的期权：佣金 $0.65 + OCC $0.025 + 交易所/监管费约 $0.05 ≈ 约 $0.72/张的固定费用，占总权利金（$300）约 0.24%。但如果价差是 $0.20（来回 $40），价差成本反而是固定费用的 55 倍。

最容易被误解的一点： 网上说“期权手续费是股票 10 倍/20 倍”，通常只算了佣金，把 commission 和 spread 混为一谈。严谨的说法是：期权的“固定费用”以“每合约”计、比股票多几层（交易所费+清算费+监管费），但真正决定贵不贵的是你交易的合约流动性（价差）和资金规模（冲击）。

17术语表 Glossary 点击展开，每条都带“为什么重要”

按主题分组，作为全文的快速检索工具。

收益与风险：Alpha / Beta / Sharpe / 波动率 / 回撤 / 敞口

Alpha： 市场（Beta）解释不了的那部分收益，来自策略自身能力。

Beta： 对市场整体涨跌的敏感度；也是“市场收益”的代称。

Sharpe Ratio： （策略收益 − 无风险利率）÷ 波动率，衡量每单位风险换来的超额收益。

Volatility： 收益的波动幅度（年化标准差），风险最常用的代理。

Max Drawdown： 从历史峰值到谷底的最大跌幅，决定资金和心态能不能扛住。

Exposure： 对某风险因素（市场、行业、波动率…）的暴露量。

期权：Call / Put / 行权价 / 权利金 / ITM / ATM / OTM / 内在价值 / 时间价值

Call： 以行权价买入的权利；Put： 以行权价卖出的权利。

Strike Price： 行权价 K，约定买卖的价格。

Premium： 权利金，买方付给卖方的价格（1 张 = 100 股）。

ITM/ATM/OTM： 实值/平值/虚值——立即行权能否赚钱、赚多少的状态。

Intrinsic Value： 内在价值 = 立即行权能赚的钱（max(S−K,0) 或 max(K−S,0)）。

Time Value： 时间价值 = 期权价格 − 内在价值，代表“未来还有可能发生好事”的价钱，随到期衰减。

Greeks：Delta / Gamma / Theta / Vega

Delta： 股价每变 $1 期权价格变多少；Call 0~1、Put −1~0。

Gamma： Delta 的变化速度；ATM 且临近到期时最大，意味着 Delta 不稳定。

Theta： 时间流逝的损耗；买方付、卖方收，临近到期加速。

Vega： 隐含波动率每变 1 个百分点期权价格变多少；买方受益于波动率上升。

波动率：HV / RV / IV / 波动率微笑 / 做空波动率 / Volatility Drag

Historical Volatility： 用过去数据算的波动率（后视镜）。

Realized Volatility： 一段已过去区间里实际发生的波动。

Implied Volatility： 从期权价格反推的、市场对未来波动的定价（挡风玻璃）。

Volatility Smile/Skew： 不同行权价的 IV 并不相同，形成的微笑/斜偏曲线。

做空波动率： 卖期权收权利金，赌实际波动 < 隐含波动；尾部风险大（2018 年 XIV 案例）。

Volatility Drag： 杠杆产品每日重置带来的复利损耗（TQQQ 长期跑输“3×总收益”的原因）。

市场结构：流动性 / 容量 / 滑点 / 市场冲击 / Open Interest / 买卖价差

Liquidity： 能不能按合理价格、以足够量成交；期权是“行权价×到期×Call/Put”的流动性曲面。

Capacity： 策略不显著损害收益时能装的最大资金量；Alpha 总量有限，钱多会摊薄。

Slippage： 预期成交价与实际成交价之差。

Market Impact： 自己订单把价格推走的幅度。

Open Interest： 未平仓合约数，反映期权合约的存量深度。

Bid-Ask Spread： 买价与卖价之差，通常比佣金更贵。

策略与执行：市场中性 / 统计套利 / 无风险套利 / 因子暴露 / 交易频率 / 机器学习

Market Neutral： 多空对冲后对市场净暴露≈0（Beta≈0）。

Risk-free Arbitrage： 理论上的无风险锁价差；现实中几乎不存在（成本/延迟/对手方/融资……）。

Statistical Arbitrage： 基于模型与均值回归的套利，有风险，赚期望为正。

Factor Exposure： 对风格因子（价值/动量/规模等）的暴露；低频策略常携带。

交易频率： 多久交易一次；与 Beta 高低没有必然关系（统计倾向≠规律）。

机器学习： 流水线里的一环——在订单簿/波动率/执行优化环节很有用，纯收益预测环节信噪比太低、易过拟合。

指数与产品：VIX / SPX / QQQ / TQQQ / VXX / XIV / Benchmark

VIX： Cboe 波动率指数——SPX 期权隐含的 30 天预期波动率（年化），是 IV 不是 HV。

SPX： 标普 500 指数及其期权；VIX 的数据来源。

QQQ： 追踪纳斯达克 100 的 ETF（费率约 0.18%–0.20%）。

TQQQ： 纳指 100 每日 3 倍杠杆 ETF（费率约 0.82%–0.97%），每日重置，长期≠3×。

VXX： 做多 VIX 期货的 ETN/ETF 类产品，长期受期货展期损耗。

XIV： 曾经的做空 VIX 期货 ETN，2018 年 2 月 5 日单日跌约 85%–96% 后被清算。

Benchmark： 基准指数，用来评估策略跑赢/跑输。
